# MLB First Basemen Analysis

This project analyzes MLB first basemen using Python, comparing player performance across key offensive and value metrics.

## Tools Used
- Python
- pandas
- matplotlib
- numpy

## What I Did
- Cleaned and structured player-level data
- Compared performance using OPS, WAR, HR, and RBI
- Built a composite scoring model to rank players
- Created visualizations to communicate insights

## Outputs
- Ranked dataset of first basemen
- OPS comparison chart
- HR vs WAR scatter plot
- Overall player ranking visualization

## Why This Matters
This project demonstrates my ability to work with sports data, build analytical pipelines, and translate statistical outputs into actionable insights—skills directly applicable to sports analytics and strategy roles.
